# Plan S-004: Walking skeleton (frontend to gateway to both services)

**Story:** `docs/backlog/stories/S-004.md` · **Objective:** prove the whole chain and the error model with a health query before any feature work.

## Preconditions
S-001 (builds and services), S-003 (frontend shell) Done. Owner runs all backend commands (D15).

## Tasks
- **Services:** register `grpc.health.v1` on movie-service and people-service; set max inbound message size (1 MiB, configurable); log `correlationId` from gRPC metadata into MDC via a server interceptor.
- **Gateway:** Spring for GraphQL with `schema.graphqls`; resolver for `health` calling both health services with 2 s deadlines; `CorrelationIdFilter` (accept or create `X-Correlation-Id`) plus a client interceptor adding it to gRPC metadata; `DataFetcherExceptionResolver` mapping per architecture section 6; CORS bound to `FRONTEND_ORIGIN`; security headers filter; max query depth/complexity instrumentation; introspection only in `dev` profile.
- **Mapping:** a `GrpcErrorMapper` implementing the table in ADR-005, including `credit.person.not_found` and `id.invalid` as `VALIDATION_FAILED` with `fieldErrors`.
- **Frontend:** footer status component calls `health` through `lib/api/client.ts`; shows loading, ok and degraded states.
- **`scripts/dev.sh`:** starts the three services (`./gradlew :<m>:bootRun`) and `pnpm dev`, ports from env, logs to `data/logs/`; `--check` polls the four health endpoints and exits non-zero on timeout.

## Contract changes
None beyond the approved schema (`health`, `ServiceHealth`).

## Tests
- Table-driven `GrpcErrorMapperTest`: one case per row of the ADR-005 table.
- GraphQL test (`GraphQlTester`) for `health` with fake gRPC stubs: both up, one down, both down, deadline exceeded.
- In-process gRPC test for the health service and message-size limit.
- Fault injection (owner): stop `people-service`, query `health`, expect `UNAVAILABLE` within 2 s, not a hang.
- Frontend component test for the footer states.

## Security and regression
CORS rejects another origin (test); introspection disabled when profile is not `dev`; no internals in messages.

## Commands (owner)
```
./gradlew :api-gateway:test :movie-service:test :people-service:test --console=plain 2>&1 | tee reports/S-004/test.log
./scripts/dev.sh &
./scripts/dev.sh --check 2>&1 | tee reports/S-004/dev-check.log
curl -s localhost:8080/graphql -H 'content-type: application/json' -d '{"query":"{ health { service status } }"}' | tee reports/S-004/health.json
kill %1   # stop the stack; then stop people-service only and repeat the curl for the degraded case
cd frontend && pnpm test -- --run && cd ..
```

## Completion criteria
Each story AC has a saved log; fault-injection output shows `UNAVAILABLE` within the deadline; reviewer agent has read the logs.

## Rollback
Revert the gateway and service interceptors; the schema and docs stay.
