# S-301: Artwork validation and storage in movie-service

**Epic:** E03 Artwork  
**Priority:** Must · **Size:** L · **Order:** 14 · **Wave:** 4  
**Status:** Draft (Phase 4)  
**Depends on:** S-201  
**Requirements:** FR-ART-01, FR-ART-02, NFR-SEC-02, NFR-ARCH-05, NFR-REL-03  
**BRD acceptance criteria owned:** AC-FR-ART-02-1, AC-FR-ART-02-2

## Objective

Artwork validation and storage in movie-service.

## Acceptance criteria

- `AC-FR-ART-02-1`: as defined in `docs/requirements/BRD.md` section 10.
- `AC-FR-ART-02-2`: as defined in `docs/requirements/BRD.md` section 10.
- `S-301.AC1`: `UploadArtwork` client-streaming RPC: metadata first, chunks next; size counted while receiving and aborted above 5 MiB.
- `S-301.AC2`: Type from magic bytes then header decode; reject over 6000×6000, 0 bytes, GIF, SVG, truncated and renamed files; declared type/size are ignored.
- `S-301.AC3`: Temp file then atomic commit; cancel, error or deadline leaves no file (BR-11, EC-07, EC-08).
- `S-301.AC4`: Replacing artwork removes old files after the DB commit; concurrent uploads for one movie end with exactly one artwork (EC-09).
- `S-301.AC5`: Streaming a 5 MiB file works with a constrained heap (NFR-ARCH-05).
- `S-301.AC6`: Streaming test runs with the JVM heap limited to `-Xmx128m` and a 5 MiB upload; dimensions are read from the image header before any full decode, a 6000×6000 image is accepted and 6001×1 or 1×6001 is rejected.
- `S-301.AC7`: Protocol violations map to `INVALID_ARGUMENT`: chunk before metadata, two metadata messages, empty stream; unknown movie → `NOT_FOUND`; a movie deleted mid-upload leaves no files.
- `S-301.AC8`: Liquibase changeset for `artwork` (with nullable `thumbnail_path` until S-302); startup sweeps `tmp/` of stale `.part` files; `DeleteMovie` and replace remove original and thumbnail files.

## Business rules and edge cases

- BR-02, BR-08; server-generated names; files under `ARTWORK_DIR` only (no path traversal).

## Test expectations

- Unit: upload test matrix (EC-05/06 samples incl. exact 5 MiB and +1 byte, polyglot, traversal names).
- Integration: in-process gRPC streaming, cancel mid-stream, filesystem assertions.
- Contract: error codes `artwork.*`.

## Definition of done

Apply `docs/backlog/definition-of-done.md` in full, plus the criteria above. No criterion is complete without command output as evidence.

## Notes

## Why this design (for the walkthrough)

Security-critical: all trust decisions about uploaded bytes live in one place.
