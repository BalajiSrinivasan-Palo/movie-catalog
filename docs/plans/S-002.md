# Plan S-002: Quality gates, hooks and CI

**Story:** `docs/backlog/stories/S-002.md` · **Objective:** gates that fail loudly, shared by the git hook, the Claude Code hook and CI.

## Preconditions
S-001 Done (so ktlint, detekt and Kover can be wired). `scripts/verify.sh`, `scripts/hooks/guard-bash.sh` and `scripts/check_traceability.py` already exist.

## Tasks
- **Backend config:** ktlint and detekt Gradle plugins with `detekt.yml`; Kover with a verification rule of 80% line coverage on `*.service.*` and `*.domain.*` packages, excluding generated code.
- **`scripts/secret_scan.py`:** regex for AWS keys, private key headers, `password=`/`token=` literals, `.env` files tracked; exits 1 on a match. Called by `verify.sh`.
- **Git hook:** `scripts/hooks/pre-commit` runs `verify.sh`; `scripts/install-hooks.sh` copies it to `.git/hooks/`.
- **CI:** `.github/workflows/verify.yml` (JDK 21, Node 22, pnpm) running `./scripts/verify.sh`; stays unused until the repo is pushed.
- **Audit steps:** `scripts/audit.sh` runs the Gradle dependency vulnerability check and `pnpm audit --audit-level=high`, writing to `reports/audit/`.
- **Extend `verify.sh`:** add `secret_scan.py`; keep the "NOT RUN" lines for gates whose tooling is absent and make the final line say which gates did not run.

## Tests (gate negative tests)
Planted lint violation, failing unit test and fake key (`AKIA...`) each make `verify.sh` exit non-zero. Hook guard tested with the three samples already used in the repo history of this session (`ls` allowed; `--no-verify`, `rm -rf` blocked).
