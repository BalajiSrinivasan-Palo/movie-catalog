# Plan S-001: Repository and build scaffold

**Story:** `docs/backlog/stories/S-001.md` · **Objective:** a Gradle multi-module build that compiles the contracts and starts three empty Spring Boot services against empty data directories.

## Preconditions and dependencies
- No story dependencies. **Blocker (AC0):** owner's machine must resolve Maven Central and the Gradle plugin portal, with JDK 21 and Gradle available (the Mac has `~/.gradle` and `~/.m2`).
- Versions are not yet chosen. They are chosen in step 1 from real resolution, then recorded in ADR-013 and ADR-004.

## Steps (owner runs commands; Claude writes files)
1. **Version discovery (owner):** `curl -s https://start.spring.io/metadata/client | python3 -m json.tool | head -60` to read the current stable Spring Boot; then generate a reference skeleton in a scratch directory (not in the repo): `curl -s https://start.spring.io/starter.zip -d type=gradle-project-kotlin -d language=kotlin -d javaVersion=21 -d dependencies=web,data-jpa,liquibase,h2,actuator -o /tmp/skel.zip && unzip -q /tmp/skel.zip -d /tmp/skel`. Paste back `/tmp/skel/build.gradle.kts` and the Boot/Kotlin versions. Claude uses those as the verified baseline.
2. **Claude writes:** `settings.gradle.kts` (modules `contracts`, `movie-service`, `people-service`, `api-gateway`), `gradle/libs.versions.toml`, root `build.gradle.kts`, one `build.gradle.kts` per module, Gradle wrapper instructions (`gradle wrapper --gradle-version <from skeleton>` run by owner once).
3. **contracts module:** protobuf Gradle plugin generating Java/Kotlin stubs from `src/main/proto`; `protoc` and the gRPC plugin as artifacts (no local install).
4. **Services:** `MovieServiceApplication`, `PeopleServiceApplication`, `GatewayApplication`; `application.yml` with ports 9091/8081, 9092/8082, 8080 and env-var overrides from architecture section 10; Liquibase `db.changelog-master.yaml` with an empty baseline; Actuator health.
5. **gRPC wiring (ADR-004):** first try Spring gRPC if compatible with the Boot version from step 1; otherwise grpc-java with `SmartLifecycle` server beans. Record the outcome in ADR-004 (status Accepted) and ADR-013 (versions).
6. `.gitignore` (`data/`, `build/`, `node_modules/`, `reports/`, `.idea/`, `.gradle/`).
7. **NFR-ARCH-02 check:** `scripts/check_no_http_between_services.sh` greps service sources for `RestTemplate`, `WebClient`, `RestClient`, `HttpClient`, `java.net.http` and fails if found outside the gateway's artwork code.

## Files expected to change
`settings.gradle.kts`, `build.gradle.kts`, `gradle/**`, `contracts/build.gradle.kts`, `*/build.gradle.kts`, `*/src/main/kotlin/**/Application.kt`, `*/src/main/resources/application.yml`, `*/src/main/resources/db/changelog/**`, `.gitignore`, `scripts/check_no_http_between_services.sh`, `docs/adr/ADR-004`, `ADR-013`.

## Contract changes
None (protos already exist; this story only compiles them).

## Tests

- Liquibase empty-start test: start with a temp data dir, assert changelog applied.
- Build smoke: `./gradlew build`.

## Security and regression
