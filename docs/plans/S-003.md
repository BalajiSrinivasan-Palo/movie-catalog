# Plan S-003: Frontend scaffold, design system and shared feedback components

**Story:** `docs/backlog/stories/S-003.md` · **Objective:** a verified SvelteKit SPA scaffold with shared components and an API client. **Implement and review in two parts:** 3a (scaffold, tooling, gate wiring) and 3b (components, client, message catalogue).

## Preconditions
None (independent of the backend). Frontend work can be built and tested directly, since npm is reachable.

## Part 3a: scaffold and tooling
- `frontend/` created with SvelteKit (`pnpm dlx sv create`), TypeScript strict, `adapter-static` with `fallback: 'index.html'`, `export const ssr = false; export const prerender = false;` in the root layout.
- Tooling: ESLint (with a rule banning `{@html}` via `svelte/no-at-html-tags`), Prettier, `svelte-check`, Vitest + jsdom + `@testing-library/svelte`, Playwright config (browsers installed later by S-603).
- Vite dev proxy `/graphql` and `/artwork` to `http://localhost:8080`.
- Scripts in `package.json`: `check`, `lint`, `test`, `build`, `test:coverage`.
- Wire into `scripts/verify.sh` (already calls `pnpm check`, `lint`, `test`, `build`).
- Global CSS tokens (colours with 4.5:1 contrast, spacing, focus ring), breakpoints 600/960 px, layout shell with header and nav and a search-box slot.

## Part 3b: components and client
Components with tests: `Button` (pending state, disabled), `TextField`/`TextArea`/`Select` (label, error, `aria-describedby`), `Dialog` (focus trap, Esc, returns focus), `Toast` store and region (`aria-live="polite"`), `Skeleton`, `Pagination`, `ProgressBar` (`role=progressbar`, `aria-valuenow`).
- `lib/api/client.ts`: `gql(query, variables, {signal})` using `fetch`; maps `errors[].extensions` to a typed `ApiError { code, fieldErrors, correlationId }`; network failure to `UNAVAILABLE`-like client error.
- `lib/messages.ts`: catalogue for every `messageKey` in BRD section 7; test parses `docs/requirements/BRD.md` and fails if any key lacks text.
- Touch target test: shared interactive components have min 44 px via CSS and a test on computed style.

## Contract changes
None.

## Tests
Vitest component tests per component including keyboard behaviour; client unit tests (success, GraphQL error, network error, abort); fake-timer test for Toast; message catalogue completeness test.

## Security and regression
No `{@html}`; no new runtime dependencies beyond Svelte/SvelteKit (dev tools only); the client sends no cookies or credentials.

## Commands (run from `frontend/`; Claude runs these directly here)
```
pnpm install --frozen-lockfile
pnpm check && pnpm lint && pnpm test -- --run && pnpm build
cd .. && ./scripts/verify.sh
```
