# S-503: Show more results per group

**Epic:** E05 Search  
**Priority:** Should · **Size:** S · **Order:** 29 · **Wave:** 7  
**Status:** Draft (Phase 4)  
**Depends on:** S-502  
**Requirements:** FR-SRC-04  
**BRD acceptance criteria owned:** AC-FR-SRC-04-1

## Objective

Show more results per group.

## Acceptance criteria

- `AC-FR-SRC-04-1`: as defined in `docs/requirements/BRD.md` section 10.
- `S-503.AC1`: Each group has 'Show more' that appends the next page and hides when exhausted; a failed page load keeps existing results and offers retry.
- `S-503.AC2`: 'Show more' uses `searchMovies` or `searchPeople` for the one group only and de-duplicates by id when pages overlap.

- See the BRD rules and edge cases referenced by the acceptance criteria.

## Test expectations

- Component: append, exhaustion, failure.
