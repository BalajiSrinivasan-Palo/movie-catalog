# S-305: Show artwork: thumbnails in lists, originals on detail

**Epic:** E03 Artwork  
**Priority:** Must · **Size:** S · **Order:** 17 · **Wave:** 7  
**Status:** Draft (Phase 4)

## Objective

Show artwork: thumbnails in lists, originals on detail.

## Acceptance criteria

- `AC-FR-ART-05-1`: as defined in `docs/requirements/BRD.md` section 10.
- `S-305.AC1`: List cards use `thumbnailUrl` with lazy loading and fixed aspect ratio (no layout shift); detail uses `url`; missing artwork shows the placeholder.
- `S-305.AC2`: Broken image URL falls back to the placeholder.
- `S-305.AC3`: Cards reserve space with a fixed `aspect-ratio` (asserted in a component test) so there is no layout shift.

## Business rules and edge cases

- See the BRD rules and edge cases referenced by the acceptance criteria.

## Test expectations

- Component: image, missing, broken-image fallback.
- Integration: list of 20 with thumbnails under 1 MB (NFR-PERF-05).
