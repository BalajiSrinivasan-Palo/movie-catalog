## Objective

Performance and security verification.

## Acceptance criteria

- `S-604.AC1`: Timing script reports p95 for list, detail, search over 50 requests on the seed dataset and a 5 MiB upload; results saved to `reports/perf.md` with machine description; targets not met are reported, not hidden.
- `S-604.AC2`: Security review by the security agent covers upload, injection, CORS, headers, GraphQL limits; dependency audits saved to `reports/`.
- `S-604.AC3`: A generator creates 1,000 movies and 1,000 people (via GraphQL) as the NFR-PERF dataset; timing is measured on that volume, not on the small demo seed.
- `S-604.AC4`: Release gate: no open high or critical security finding from the security-reviewer agent.
