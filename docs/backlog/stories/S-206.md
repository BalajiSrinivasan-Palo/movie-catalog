# S-206: Sort and filter movies

**Epic:** E02 Movie management  
**Priority:** Should · **Size:** M · **Order:** 27 · **Wave:** 5  
**Status:** Draft (Phase 4)  
**Depends on:** S-202  
**Requirements:** FR-MOV-06, NFR-SEC-01  
**BRD acceptance criteria owned:** AC-FR-MOV-06-1, AC-FR-MOV-06-2

## Objective

Sort and filter movies.

## Acceptance criteria

- `AC-FR-MOV-06-1`: as defined in `docs/requirements/BRD.md` section 10.
- `AC-FR-MOV-06-2`: as defined in `docs/requirements/BRD.md` section 10.
- `S-206.AC1`: Sort by title or year asc/desc; filter by genre and year or year range; state in URL query params.
- `S-206.AC2`: Sorting is stable across pages (secondary key = id).
- `S-206.AC3`: yearFrom/yearTo must lie within 1888..current year + 5 and yearFrom ≤ yearTo, else `filter.year.invalid`; unknown sort field → `sort.invalid`; changing a filter resets the page to 0; equal yearFrom and yearTo behaves as a single year.

## Business rules and edge cases

- yearFrom ≤ yearTo else `paging.invalid`-style validation error; unknown sort field rejected.

## Test expectations

- Unit: filter combinations, empty result, boundaries.
- Integration: query correctness with 50+ rows across pages.
- Component: controls, URL sync, back button.

## Definition of done

Apply `docs/backlog/definition-of-done.md` in full, plus the criteria above. No criterion is complete without command output as evidence.
