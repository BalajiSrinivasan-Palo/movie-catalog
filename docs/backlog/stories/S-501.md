# S-501: Search backend and gateway merge

**Epic:** E05 Search  
**Priority:** Must · **Size:** M · **Order:** 25 · **Wave:** 4  
**Status:** Draft (Phase 4)  
**Depends on:** S-201, S-101  
**Requirements:** FR-SRC-01, NFR-SEC-04, NFR-PERF-02, NFR-TEST-03  
**BRD acceptance criteria owned:** AC-FR-SRC-01-1, AC-FR-SRC-01-2

## Objective

Search backend and gateway merge.

## Acceptance criteria

- `AC-FR-SRC-01-1`: as defined in `docs/requirements/BRD.md` section 10.
- `AC-FR-SRC-01-2`: as defined in `docs/requirements/BRD.md` section 10.
- `S-501.AC1`: `SearchMovies` (title, synopsis, genre names) and `SearchPeople` (name, bio); gateway `search` runs both in parallel and returns two paged groups.
- `S-501.AC2`: Query trimmed, 2–100 characters else `search.query.invalid`; `%`, `_`, `\` match literally (EC-12).
- `S-501.AC3`: Contract change: gateway also exposes `searchMovies(query, page)` and `searchPeople(query, page)` for single-group paging.

## Business rules and edge cases

- D9: substring, case-insensitive, no ranking.
- BR-09: results expose only public ids.

## Test expectations

- Unit: pattern escaping, length bounds (1, 2, 100, 101, whitespace only).
- Integration: SQL injection strings, wildcard literals, accents.
- Contract: both backends fail → one clear error.
- Genre text: query 'sci-fi' matches Sci-Fi movies; 'sci_fi' is treated literally and does not match.

## Definition of done

Apply `docs/backlog/definition-of-done.md` in full, plus the criteria above. No criterion is complete without command output as evidence.
